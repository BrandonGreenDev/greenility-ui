# Design tokens

Tokens are the only source of visual values in Lumora. Component CSS never contains a raw
color, spacing or duration; it references a `--lu-*` custom property instead.

There are three layers:

1. **Palette**: raw color primitives (`--lu-palette-iris-600`). Components never use these
   directly.
2. **Semantic tokens**: intent-based names (`--lu-color-accent-solid`) that point at a
   palette step. Each theme is a different mapping, which is all it takes to support dark mode.
3. **Scales**: theme-independent tokens for type, space, radius, motion, z-index and sizes.

All tokens are authored in `src/tokens/tokens.ts`. `npm run tokens` generates
`tokens.css` from it, and CI fails if the two drift apart. Everything on this page is
rendered from that same file.

## Motion

Durations and easing curves. Under `prefers-reduced-motion: reduce`, every duration
becomes `0.01ms`. That is effectively instant, but still fires `transitionend`, so
components that wait for an exit animation never get stuck.
