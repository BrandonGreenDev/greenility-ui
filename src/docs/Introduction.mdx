# Greenility UI

Greenility is an accessible, themeable React component library. It is written in strict
TypeScript and styled with design tokens and CSS Modules, with no UI framework underneath
and no runtime dependencies.

To see the components working together, open the [Showcase](?path=/story/showcase--light)
(also in [dark](?path=/story/showcase--dark)).

## Accessibility

- **Native first.** Native elements are used wherever they fit. Custom widgets follow the
  [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/), and the target is WCAG 2.2 AA.
- **Keyboard and focus.** Every component is keyboard operable with a visible focus ring.
  Overlays manage focus and return it when they close.
- **Announcements.** Changes are announced through polite live regions, once per action.
  Field errors are linked with `aria-describedby` and are read on focus.
- **User settings.** Motion collapses under `prefers-reduced-motion`, and controls stay
  visible in forced colors (Windows High Contrast).
- **Tested.** Unit tests run axe in jsdom, and token pairs are contrast-tested in both
  themes. CI also runs axe on every story in light and dark, in Chromium, Firefox and WebKit.
  Open the **Accessibility** panel on any story to see a live axe report.

**Not yet verified:** the components have not been tested manually with a screen reader
(NVDA, JAWS or VoiceOver).

## Getting started

Import the stylesheet once at the root of your app. Wrap the app in `ToastProvider` if you
use toasts:

```tsx
import 'greenility-ui/styles.css';
import { Button, ToastProvider, useToast } from 'greenility-ui';

function SaveButton() {
  const toast = useToast();
  return (
    <Button
      variant="primary"
      onClick={() => toast.show({ tone: 'success', title: 'Changes saved' })}
    >
      Save changes
    </Button>
  );
}

export function App() {
  return (
    <ToastProvider>
      <SaveButton />
    </ToastProvider>
  );
}
```

## Theming

Set `data-theme` to `light` or `dark` on `<html>` or on any container. Use `system` on
`<html>` to follow the operating system. Themes can nest, so a dark panel can sit inside a
light page, and no provider is needed.

```ts
document.documentElement.dataset.theme = 'dark'; // or 'light' | 'system'
```

Use the **Theme** button in the toolbar above to switch every story between light, dark, or
both side by side.
