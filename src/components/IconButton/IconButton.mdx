# IconButton

IconButton is a square Button whose only content is an icon, such as a close or settings
control. It shares Button's variants, sizes and loading behavior. Because there is no visible
text, the `label` prop is required and becomes the button's accessible name.

## Usage

```tsx
import 'greenility-ui/styles.css'; // once, at the root of your app
import { IconButton } from 'greenility-ui';

<IconButton label="Close" icon={<CloseIcon />} onClick={close} />;
```

`CloseIcon` stands for any icon element from your own icon set. The icon is decorative and
wrapped in `aria-hidden`.

### Tooltip

By default the `label` is also shown as a small tooltip, so sighted mouse and keyboard users
can read what the icon means. It appears after a short delay on hover and immediately when the
button receives keyboard focus (not on a mouse click or touch). <kbd>Escape</kbd> hides it
without moving focus, and the pointer can move onto it without it closing. It does not show
while the button has `aria-expanded="true"`, for example while it is the trigger of an open
Menu. See [Tooltip](?path=/docs/components-tooltip--docs) for the full behavior.

<Canvas of={IconButtonStories.TooltipOn} />

The tooltip is decorative: it is hidden from assistive technology (`aria-hidden`, no
`role="tooltip"` and no `aria-describedby`), because it repeats the name that already comes
from `aria-label`. Screen readers announce the button once, with no extra description.

Use `tooltipPlacement` (`'top'`, `'bottom'`, `'start'`, `'end'`, default `'top'`) to choose the
preferred side. It flips to the opposite side when there is no room, and `start`/`end` follow
the nearest `dir` attribute.

<Canvas of={IconButtonStories.TooltipPlacements} />

Set `tooltip={false}` when a tooltip would only get in the way, for example when the same text
is already visible next to the button.

<Canvas of={IconButtonStories.TooltipOff} />

The bubble is rendered as the button's next sibling (not a wrapper) and stays in the DOM while
hidden. It takes no space and does not change the layout, but it does count for structural
selectors such as `:last-child` or `+` on the button's siblings.

## Props

The ref and any other props go to the native `<button>`. All Button props are supported except
`children`, `startIcon`, `endIcon`, `aria-label` and `aria-labelledby`.

## Accessibility

**Pattern.** [WAI-ARIA APG Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/), met by
a native `<button>` with `aria-label`.

**Screen reader.** The name is `label`, applied as `aria-label`. The icon and the tooltip are
hidden. Loading
behaves exactly like Button: the name stays the same, the button is announced as unavailable,
and `loadingLabel` is read as the description.

**What you must provide.**

- A `label`. It is required by the types and must be non-empty. An empty or whitespace-only
  label logs a console warning, because the button would have no name.
- A label that matches what the icon means in this place. A trash icon that removes a row from
  a list is "Remove Site A", not "Trash" or "Delete file".
- A unique label when several icon buttons act on different items, such as "Edit Site A" and
  "Edit Site B".

## Do / Don't

**Do**

- Write the label as the action, such as "Close dialog" or "Open settings".
- Include the target when there are several similar buttons, such as "Remove Site A".
- Use icons that are widely understood, such as close, search or settings.
- Use `ghost` for low-emphasis controls inside toolbars and alerts.

**Don't**

- Don't pass an empty label or a label that only describes the picture, such as "X" or "Cross".
- Don't use an IconButton when there is room for text. A text Button is clearer.
- Don't use a label that disagrees with the icon. Sighted and screen reader users must get the
  same meaning.
- Don't rely on the tooltip to explain the icon. The label is the name, and touch users never
  see the tooltip.
- Don't put a separate Tooltip around an IconButton. It already shows its label; use
  `tooltip={false}` and a standalone Tooltip only when the hint must say something different.
